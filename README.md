# Voice Work Website

GitHub-ready version of the Voice Work website.

## Files
- `index.html` — page structure and content
- `css/styles.css` — all styling, responsive rules, and animations
- `js/script.js` — page interactions
- `assets/images/` — place future local image assets here

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder (especially `index.html`, `css/`, `js/`, and `assets/`).
3. In GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**, select the main branch and `/ (root)`, then save.

## Easy editing
The active marquee/trust/FAQ rules are grouped at the bottom of `css/styles.css` under **VOICE WORK — ACTIVE FINAL OVERRIDES** so they are easy to find.
